# University Management System, E-Commerce Data Analysis, and AI Ethics in Healthcare

This repository contains solutions and project work for three major questions covering **Object-Oriented Programming (OOP)**, **Data Analysis**, and **Ethical AI in Healthcare**. Each section demonstrates practical applications of computing concepts while ensuring accountability, scalability, and ethical responsibility.



### Enhanced OOP: University Management System

This project extends a school management system into a **comprehensive university management system**, leveraging **OOP principles** to handle departments, courses, and grading.  

### Data Analysis: E-Commerce Data Analysis

This project demonstrates **web scraping, data cleaning, statistical analysis, visualization, and prediction** in the context of online retail pricing, ratings, and inventory management.  


### Data Ethics: AI Ethics in Healthcare

This project evaluates the ethical challenges of **AI in healthcare**, focusing on privacy, bias, fairness, and global equity. 

## Technologies Used
- **Programming Languages:** Python(3.13) (OOP, data analysis)
- **IDE:** PyCharm Community Edition 2025.1.1.1
- **Libraries & Tools:**  
  - `BeautifulSoup`, `requests` (Web Scraping)  
  - `pandas`, `numpy` (Data Cleaning & Analysis)  
  - `matplotlib`, `seaborn`, `plotly` (Visualizations)  
  - `scikit-learn` (Regression & Prediction)
  - `PySimpleGUI` (OOP UI)
